# x402: pay per call without an account

`https://bananabanana.pro/api/x402` is a separate HTTP API for agents paying with
USDC on Base. It requires no BananaBanana account, API key or OAuth connection.
The deployed payment protocol is **x402 v1**, using `X-PAYMENT` and
`X-PAYMENT-RESPONSE` headers. An unpaid request returns HTTP **402** with exact
payment requirements. It is not a JSON-RPC MCP endpoint; MCP clients should use
`https://bananabanana.pro/api/mcp` with OAuth or a Bearer API key.

## Discovery and request format

- `GET /api/x402` returns the current tools, prices and constraints for free.
- `GET /.well-known/x402` and `GET /.well-known/x402.json` expose discovery metadata.
- `POST /api/x402` accepts `{ "tool": "...", "arguments": { ... } }`.

To quote a cheap image without spending anything:

```bash
curl --silent --show-error https://bananabanana.pro/api/x402 \
  -H 'Content-Type: application/json' \
  -d '{"tool":"generate_image","arguments":{"prompt":"a watercolor lighthouse at dawn","model":"nano-banana-2-lite","resolution":"1024"}}'
```

The response is HTTP 402 with `x402Version: 1` and an `accepts` array containing
`scheme`, `network`, `asset`, `payTo`, `maxAmountRequired`, `resource`,
`maxTimeoutSeconds` and token-domain `extra` fields. Sign the returned requirements
with an x402 v1-compatible wallet client, encode its payment payload as base64 JSON
in `X-PAYMENT`, and repeat the same request. USDC has six decimals: a $0.03 quote
uses `maxAmountRequired: "30000"`. Use the actual 402 response instead of hard-coding
the recipient, token address or price.

A discovery manifest or an empty POST advertises the cheapest possible call, not
the price for your arguments. Request an exact quote before signing a payment.
Inspect error responses before signing another authorization; a request with an
invalid tool and an existing payment header returns 400 without settling it.

## Supported tools and inputs

| Tool | Result | Payment |
|---|---|---|
| `generate_image` | Hosted image URLs in the same HTTP response | Settles only after successful generation |
| `generate_speech` | Hosted WAV URL in the same HTTP response | Settles only after valid audio |
| `generate_video` | `job_id`, then free result polling | Settles before rendering starts |

Models, pricing and applicable parameters follow the [MCP tool reference](tools.md)
and live x402 catalogue, with these differences:

- Image generation defaults to **`nano-banana-2` at 1024 ($0.06)**, while MCP defaults
  to `nano-banana-2-lite` ($0.03). Set the model explicitly to choose the cheaper one.
- Media inputs (`reference_images`, `first_frame`, `last_frame`) accept only public
  http(s) URLs or inline image data URLs. Account `job_id` references and local
  storage paths are rejected before payment.
- `reference_videos`, `source_ref`, `source_generation_id` and conversational
  `edit_from_generation_id` are unavailable. `edit_image` and `edit_video` are
  MCP-only tools.
- The exact-price payment authorizes the spend; the endpoint supplies the MCP cost
  confirmation internally. It does not require a separate MCP `confirm_cost` flow.
- Prepaid balance, top-up bonuses and promo codes apply to account-based MCP usage.
  x402 pays the quoted per-call amount directly.

## Video polling and refund credits

After a paid video call returns its `job_id`, poll the unauthenticated, free
`GET /api/x402/result/{job_id}` endpoint. Keep the job id private: it grants access
to the result and, if the job fails, its compensation token. Expect 1–10+ minutes
for video rendering.

For a failed or content-filtered video, the first failure response includes a
`refund_token`, its USD amount and `refund_expires_at`. **Save that response**:
the token is issued once and later polls do not return it again. It is a service
credit, not an on-chain USDC refund, and expires after **90 days**.

Apply it to another request as a top-level field:

```json
{
  "tool": "generate_image",
  "arguments": { "prompt": "a watercolor lighthouse", "model": "nano-banana-2-lite" },
  "refund_token": "bb_rf_YOUR_TOKEN"
}
```

The credit covers all or part of the exact price. If more payment is needed, the
402 quotes only the difference. Excess credit returns as a new token. Tokens are
single-use; keep them secret and save any replacement token returned by the call.
Image/speech failures do not settle an on-chain payment; any consumed refund credit
is reissued in the failure response.

Generated files are retained for **30 days from creation** and signed media URLs
last **24 hours**. Video polling can refresh links within the retention period.
Download image/speech files from the synchronous response before those URLs expire.
